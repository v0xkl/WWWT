# World Wide Tier Tagger

Fabric mod that shows a player's tier rankings from several tierlist networks.

## Supported networks
- MCTiers
- PVPTiers
- PVPHQ
- SubTiers
- Universal Tiers

## Universal Tiers
Since 1.3.0 the mod uses **Universal Tiers** instead of TierMC. All TierMC code, requests and assets were removed.

- 11 gamemodes: Sword, Axe, Mace, Diapot, SMP, UHC, Spear Mace, Dia SMP, Manhunt, Shieldless UHC, Cart
- Players are matched by IGN, unknown players are shown as *Unranked*
- Data is cached for 60 seconds
